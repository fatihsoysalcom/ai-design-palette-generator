# AI Design Palette Generator

This Python script simulates a basic AI-powered design tool. It takes a text prompt (a "mood" like 'calm' or 'vibrant') and generates a corresponding color palette using simple color theory rules. It demonstrates how AI tools can assist designers by automating creative tasks and providing inspiration, mirroring the concept of the AI design tools compared in the article.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python main.py`. Follow the prompts to enter a mood.
